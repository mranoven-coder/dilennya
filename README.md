# Ділення стовпчиком — тренажер

**Версія:** 1.65 (05.10.2026)
**Онлайн:** https://mranoven-coder.github.io/dilennya/
**Ліцензія:** CC BY-NC-ND 4.0

Безкоштовний інтерактивний тренажер, який навчає дітей ділити багатоцифрові числа в стовпчик. Дитина проходить кожен крок сама: вгадує цифру частки (з підказками «забагато» / «замало»), множить, віднімає — так само, як у зошиті. Працює офлайн у будь-якому браузері, можна встановити як застосунок на телефон чи комп'ютер.

## Можливості

- Чотири рівні складності: від «2 цифри ÷ 1 цифра» до «3–4 цифри ÷ 2 цифри»
- Перемикач «з остачею», щоб генерувати приклади з остачею або без
- Власний приклад: можна ввести своє ділене й дільник
- Підказки (💡, безкоштовно) і «Показати відповідь» (👀, зі штрафом до підсумкової оцінки)
- Оцінка результату зірочками залежно від кількості помилок
- Класичний вигляд стовпчика: дільник над рискою, частка під нею, як у зошиті
- Підтримка темної теми (автоматично, за налаштуваннями пристрою)
- Екранна цифрова клавіатура на комп'ютері: вікно з цифрами, яке можна перетягувати мишею (вмикається в ⚙)
- Цифри відповіді вводяться прямо в записі, як у зошиті (можна повернути поле для відповіді в ⚙)
- Телефон: панель з цифрами внизу екрана замість системної клавіатури; «Режим введення» (Авто / Комп'ютер / Телефон) у ⚙
- Працює офлайн (PWA), можна встановити як застосунок

## Технічні примітки

- Один самодостатній файл `index.html` (HTML + CSS + JS, без зовнішніх залежностей)
- `sw.js` — Service Worker для офлайн-роботи; HTML завжди береться свіжим з мережі, коли інтернет є
- `manifest.json` — опис для встановлення як PWA
- `icons/` — іконки застосунку (192×192, 512×512, apple-touch-icon, og-image для соцмереж)

## Перед публікацією

У файлах `index.html` та `manifest.json` варто замінити URL-заглушку
(`https://mranoven-coder.github.io/dilennya/`) на реальну адресу сторінки
після того, як репозиторій опублікується на GitHub Pages — інакше посилання
canonical, Open Graph та JSON-LD вказуватимуть у нікуди.
